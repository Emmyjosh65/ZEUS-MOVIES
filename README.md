# ⚙ Requirements

- Node.js
- Electron
- TMDB API Key
- ffmpeg (optional for downloads)

---

# 🔑 TMDB API Setup

1. Create account on TMDB
2. Generate API key
3. Add API key in settings
4. Restart the app

# 📦 Installation

```bash
git clone https://github.com/EmmyJosh65/zeus-netflix.git
cd zeus-netflix
npm install
npm start
```

---

# 🛠 Build App

## Windows

```bash
npm run dist:win
```

## Linux

```bash
npm run dist:linux
```

## AppImage

```bash
npm run dist:appimage
```
